# Kids Box Factory

Static single-page website for Kids Box Factory, built with plain HTML, CSS, and JavaScript.

## Files

- `index.html` — main page markup
- `styles.css` — responsive styling
- `script.js` — mobile navigation, smooth reveal effect, and contact form placeholder

## Local preview

1. Open `index.html` in your browser.
2. For the best experience, serve the folder from a local server, such as VS Code Live Server or a simple Python HTTP server:
   - `python -m http.server 8000`
3. Visit `http://localhost:8000`.

## GitHub Pages

1. Push the repository to GitHub.
2. In the repository settings, enable GitHub Pages from the `main` branch and set the site source to `/`.
3. The site will be available at `https://<username>.github.io/<repository>`.
